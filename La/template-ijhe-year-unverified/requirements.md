# Migration and submission requirements

## Verified from official Elsevier pages

- Use the Elsevier `elsarticle` class for LaTeX manuscripts.
- Use BibTeX for the bibliography; the journal-specific reference style must be checked against the current Guide for Authors.
- A locally compiled PDF is normally accepted for initial submission when the journal workflow permits PDF submission.
- When source files are requested in Editorial Manager, `.tex`, `.bib`, `.bbl`, `.bst`, `.sty`, `.cls`, figures and tables belong to the manuscript/source package.
- Editorial Manager does not process LaTeX source subfolders reliably. Flatten a submission copy so the main file, bibliography and figures are at one folder level, then compile that copy before upload.

## Current IJHE evidence

- The current journal page identifies IJHE as covering hydrogen storage, which matches the manuscript topic.
- Recent IJHE article pages display a title, author list, Highlights, Abstract, keywords, numbered sections, figures/tables, numbered references, and standard end matter.

## Recheck manually before submission

The journal-specific Guide for Authors page was blocked by a Cloudflare challenge during automated checking. Confirm these items in a normal browser immediately before submission:

- article type and any word/page limit;
- abstract and keyword limits;
- whether Highlights are mandatory and their bullet/character limits;
- whether a graphical abstract is mandatory;
- required CRediT, funding, data availability, declaration of competing interest and AI-use disclosures;
- current reference style and whether journal titles must be abbreviated;
- separate title-page requirements and blinded-review requirements;
- figure resolution/file-format rules and supplementary-file naming.

The local scaffold includes editable files for highlights and a graphical-abstract note, plus end-matter placeholders. Placeholders must be completed or removed only after the authors confirm the facts.
