# mg-la-4ni-ijhe-zh-2026

这是《La含量对Mg-xLa-4Ni合金组织演化、储氢性能及界面作用的影响》的 IJHE 中文迁移稿。原 Word 正文和插图文档只作为来源保存，未被修改。

- 默认编辑入口：`main.tex`（指向 `project/main.tex`）
- 编译根目录：`project/`
- 引擎：XeLaTeX；参考文献：BibTeX + `elsarticle-num`
- 中文字体：宋体（macOS `Songti SC`）；西文、数字：Times New Roman
- PDF：`build/main.pdf`
- 模板：`ijhe-elsarticle-year-unverified`
- 来源正文：`notes/source-docx/La添加小论文.docx`
- 来源插图：`raw_figure_ppt/source-docx/La添加小论文插图.docx`
- 迁移记录：`notes/migration_report.md`

从工作区根目录执行：

```bash
./paper build mg-la-4ni-ijhe-zh-2026
./paper preview mg-la-4ni-ijhe-zh-2026 --viewer none
```

图 4 的原始提取版保存在 `project/figures/figure-04.png`，论文实际引用的 `figure-04-times-new-roman.png` 仅替换了四个分图编号。作者、单位、通信邮箱、CRediT、利益冲突、数据可用性、基金与致谢仍待补充。IJHE 正式投稿通常需要英文稿；本版本按当前要求保留中文，后续翻译应建立独立版本。
